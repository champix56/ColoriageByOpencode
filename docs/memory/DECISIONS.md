## 2026-10-15 — Cadrage du premier livre
- Décision : produire « Coloriage anti-stress – Mandalas du Día de los Muertos ».
- Contenu : public tous âges ; thème Día de los Muertos traité de façon
  ornementale et respectueuse ; 50 illustrations type mandala ; ambiance
  mystique et ésotérique ; sans texte intérieur (hors liminaires) ; trait
  moyen régulier (1,5-2 pt) ; rendu vectoriel net sans gris ; aucune
  contrainte de contenu au-delà des règles d'AGENTS.md.
- Impression : format 8 × 10 po portrait ; sans fond perdu (marges
  blanches) ; page blanche après chaque illustration ; liminaires = page de
  titre, « ce livre appartient à », présentation du thème et du coloriage
  anti-stress, page de test des feutres ; papier blanc ; couverture
  paperback mat.
- Production : sources PNG 300 DPI ; budget de génération 0 $ ; aucune clé
  API disponible → comparaison de fournisseurs orientée options gratuites.
- Raison : choix validés explicitement par l'utilisateur en session de cadrage.
- Fichiers concernés : AGENTS.md, docs/PROJECT_BRIEF.md, docs/visual/VISUAL_BIBLE.md,
  docs/visual/VARIETY_MATRIX.md, docs/visual/ILLUSTRATION_CATALOG.md,
  docs/production/COVER_BRIEF.md, docs/production/IMAGE_PIPELINE.md,
  docs/production/PRINT_AND_KDP.md.
- Conséquences : intérieur ≈ 104 pages (4 liminaires + 50 illustrations +
  50 versos) ; dos estimé ≈ 0,234 po (à re-vérifier) ; la matrice de variété
  devient l'outil clé contre les clones de mandalas ; catalogue I001–I050
  créé en squelette.
